Claude Code Plugin · v0.1.0

Give Claude
a phone.

A two-way voice bridge for Claude Code. Make outbound calls, get rung when work is done, talk to your agent from anywhere.

MIT · Open Source Powered by Patter
What it does

Three flows. One plugin. Zero voice code.

01 / killer feature

Claude → 3rd party

/call → autonomous agent → transcript

Book a restaurant. Reschedule a dentist appointment. Ask the airline about rebooking. Claude dials, talks, and reports back with structured outcomes.

02 / autonomous

Claude → you

Stop hook → make_call → ring

/notify-me arms a Stop hook. When the long task finishes, Claude calls you with a summary and lets you talk back.

03 / inbound

You → Claude

Twilio → patter-mcp → live session

Dial your Twilio number from anywhere. Drops you straight into a voice conversation with your active Claude Code session.

Installation

Two terminals. Done.

1 Run patter-mcp

Clone, configure your API keys, leave it running. This handles all the voice plumbing.

~/dev
$ git clone https://github.com/PatterAI/patter-mcp ~/dev/patter-mcp
$ cd ~/dev/patter-mcp
$ cp .env.example .env # add your keys
$ npm install && npm run dev
[patter-mcp] Listening on :3000/mcp ✓

2 Install the plugin

One command in Claude Code. The plugin registers patter-mcp, hooks, slash commands, and the phone-agent subagent.

claude
$ claude plugin install https://github.com/PatterAI/awesome-claude-call

→ Installing claude-call v0.1.0...
→ Registering MCP server: patter-mcp
→ Loaded 6 commands, 1 subagent, 4 hooks
✓ Ready. Try /call to make your first call.

Slash commands

The whole API surface.

Command
What it does
/call <num> <objective>
Outbound third-party call. Claude pursues the goal autonomously and returns a transcript + structured outcome.
/notify-me <num>
Arms a one-shot Stop hook. When the current task finishes, Claude calls you with a summary you can talk back to.
/notify-me-cancel
Disarms the Stop hook for this session.
/dial-me-on-blocked <num>
Arms a Notification hook. Whenever Claude stalls on a permission or idle prompt, it rings you.
/dial-me-on-blocked-cancel
Disarms the Notification hook.
/calls
Lists recent calls with status, duration, and cost.
Behind the scenes

Hooks turn idle prompts into phone rings.

Hook · Stop

on-stop.sh

Fires when Claude finishes its turn. Reads the last assistant message, composes a system prompt, calls you via make_call.

→ /notify-me
Hook · Notification

on-notification.sh

Fires on permission_prompt and idle_prompt. Stays armed for the whole session — every stall rings you.

→ /dial-me-on-blocked
Hook · SessionEnd

disarm.sh

Cleans up flag files when the session ends. Also runs a 24h TTL sweep on stale flags from crashed sessions.

→ automatic
Security & privacy

Boring guarantees that matter.

01

AI disclosure on every call

Hard-coded into outbound system prompts. The agent identifies as "an AI assistant calling on behalf of the user" on the first turn. Non-overridable in v0.1.

02

Phone numbers redacted in logs

Every log entry that touches a number runs through cc_redact_phone — last 4 digits only.

03

State directory mode 0700

Flag files live in ~/.claude-call/state/, created with mkdir -m 0700. Owner-only readable.

04

Zero outbound HTTP from the plugin

The plugin only talks to your local patter-mcp. Telephony credentials never leave that one process — the plugin doesn't see them.
