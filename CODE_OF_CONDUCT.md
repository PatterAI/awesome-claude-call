# Code of conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating &mdash; opening issues, sending pull requests, posting in discussions &mdash; you agree to abide by it.

## Reporting

To report a concern, email `conduct@getpatter.com` or use GitHub's [private vulnerability reporting](https://github.com/PatterAI/awesome-claude-call/security/advisories/new) for sensitive cases. Reports are handled by the maintainers, in confidence.

## Scope

Applies in all project spaces &mdash; this repo, its issue tracker, pull requests, discussions, and any official communication channel run by PatterAI.

## Enforcement

Maintainers may remove comments, close issues or PRs, and ban contributors whose behavior violates the Covenant. The escalation ladder follows the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
